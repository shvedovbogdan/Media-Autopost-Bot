Службові дані бота.

Файл admins.json буде створено автоматично після додавання адміністратора.
Файл bot_rentals.json буде створено автоматично після оплати /rentbot.
Файл channel_payments.json буде створено автоматично для історії Stars-рахунків.
Файл backup_state.json буде створено автоматично для контролю автобекапу.
Не додавайте цю папку до публічного архіву разом із реальними даними клієнта.

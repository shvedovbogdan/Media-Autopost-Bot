## 1. Що це за проєкт

**Media Autopost Bot** — один керуючий Telegram-бот, який автоматично публікує фотографії та відео в кілька Telegram-каналів.

У чистій продажній збірці немає попередньо доданих каналів, їхніх назв, адрес або `chat_id`. Після встановлення покупець сам додає через Telegram-бота стільки власних каналів, скільки йому потрібно:

```text
/addchannel key chat_id Назва для меню
```

У цій команді важливо не плутати три різні речі:

| Поле | Що означає | Де використовується |
| --- | --- | --- |
| `key` | внутрішній ключ профілю, він же назва папки з контентом | у командах бота та в папці `channels/<key>` |
| `chat_id` | Telegram-канал, куди бот буде публікувати | `@username` публічного каналу або ID `-100...` приватного каналу |
| `Назва для меню` | зрозуміла назва, яку бачать власник і адміністратори в меню бота | у списку `/channels`, кнопках і статусі |

`key` не є назвою Telegram-каналу і не є `@username`. Наприклад, у команді:

```text
/addchannel HOTBOYS_YAOI_NS @HOT_BOYSES HOTBOYS + YAOI NS
```

- `HOTBOYS_YAOI_NS` — ключ профілю і папка `channels/HOTBOYS_YAOI_NS`;
- `@HOT_BOYSES` — Telegram-канал для публікації;
- `HOTBOYS + YAOI NS` — назва, яку буде видно в меню бота.

Для кожного нового каналу бот автоматично створює окремий профіль, папки медіа, чергу, архів і налаштування. Жорсткого обмеження кількості каналів у програмі немає; практична кількість залежить від потужності сервера, обсягу медіа та лімітів Telegram.

Профілі працюють незалежно. Для кожного каналу можна окремо налаштувати:

- Telegram `chat_id` або публічний `@username`;
- чергу фотографій і відео;
- інтервал публікації;
- українську, російську або англійську мову підписів;
- набір підписів;
- рекламний футер;
- паузу та ручну публікацію;
- адміністраторів;
- статистику й архів уже опублікованих файлів.

Канали можна додавати й видаляти в будь-який момент командами `/addchannel` і `/delchannel`.

## 2. Основні можливості

- Один процес і один Telegram-бот керують усіма каналами.
- Окрема медіатека, черга, архів і статистика для кожного каналу.
- Автоматична публікація за інтервалом від 1 хвилини до 7 днів.
- Ручна публікація командою або кнопкою.
- Автоматичне чергування фото та відео, якщо доступні обидва типи.
- Випадковий вибір файлу з черги.
- Перенесення успішно опублікованого файлу в архів.
- Генерація різноманітних підписів за часом доби.
- Захист від частого повторення схожих підписів.
- Підписи українською, російською та англійською мовами.
- Окремі набори підписів `default`, `style_1` і `style_2`.
- Додавання медіа через Telegram або безпосередньо в папки.
- Ролі власника та додаткових адміністраторів.
- Повідомлення власнику про нову помилку публікації.
- Логи з автоматичною ротацією.
- Автозапуск на Windows через Планувальник завдань.
- Автоматичний перезапуск після аварійного завершення.
- Безпечні шляхи: бот не працює з файлами за межами папки проєкту.

```text
    ├── utils/                  # безпека й робота з JSON
    ├── .env.example            # приклад секретних налаштувань

    ├── bot.py                  # точка запуску
    ├── channels.json           # налаштування профілів каналів

    ├── diagnose.py             # локальні й Telegram-перевірки
    ├── import_media.ps1        # копіювання медіа зі старих ботів

    ├── requirements.txt        # Python-залежності
    ├── server_start.bat        # безперервний серверний запуск
    ├── setup.bat               # створення середовища та встановлення пакетів
    ├── start.bat               # звичайний запуск із відкритою консоллю
    ├── README.md               # короткий старт
    └── ІНСТРУКЦІЯ.md           # повна документація
```

Стара однопапкова схема також працює для ручного запуску `start.bat`, але для серверного менеджера рекомендовано саме розташування вище: `_manager` поруч із папкою бота.

У чистій збірці є порожні робочі папки з файлами-поясненнями. Під час запуску бот перевіряє їх і автоматично створює відсутні:

```text
channels/                   # черги та архіви медіа
data/                       # список адміністраторів
stats/                      # статистика публікацій
caption_history/            # історія використаних підписів
logs/                       # журнали роботи
venv/                      # локальне середовище Python
.env                        # секретний токен і ID власника
```

### Що не повинно входити в публічний або продажний архів

- файл `.env` із токеном;
- папка `venv`;
- реальні медіафайли в `channels/`, якщо права на них не передаються;
- `data/`, `stats/`, `caption_history/` і `logs/` попереднього власника;
- кеші `__pycache__`, `.pytest_cache`, `.ruff_cache`;
- резервні копії з особистими даними;
- старі токени, паролі, ключі або приватні посилання.

Рекомендована конфігурація:

- Windows 10/11 або Windows Server;
- Python **3.12** із Python Launcher `py`;
- доступ до інтернету;
- Telegram-бот, створений через `@BotFather`;

Бот не потребує окремої СУБД, Docker або платного API.

## 5. Встановлення на Windows

### Крок 1. Встановити Python

Встановіть 64-бітний Python 3.10, 3.11 або 3.12 із [python.org](https://www.python.org/downloads/). Рекомендовано Python 3.12. Під час встановлення увімкніть:

- `Add Python to PATH`;
- `Install Python Launcher`.

Перевірка у `cmd` або PowerShell:

```powershell
py -3.12 --version
```

### Крок 2. Розпакувати проєкт

Рекомендований шлях:

```text
D:\Bots\Media_Autopost_Bot
```

Не запускайте бота безпосередньо всередині ZIP-архіву.

### Крок 3. Запустити налаштування

Запустіть:

```text
start.bat
```

Скрипт автоматично:

1. знайде Python 3.12, 3.11 або 3.10 через `py`, `python` чи `python3`;
2. перевірить наявну `venv` або створить нову;
3. встановить залежності;
4. створить `.env` на основі `.env.example`;
5. попросить ввести `BOT_TOKEN` і цифровий `OWNER_ID`, перевірить їх та збереже локально;
6. залишить консоль відкритою, якщо виникне помилка.

Після першого налаштування бот запускається автоматично. Відкривати `.env` вручну не потрібно.

Якщо `venv` була скопійована разом із проєктом, перенесена з іншого ПК, створена несумісним Python або пошкоджена, `setup.bat` автоматично видалить тільки цю відновлювану службову папку та створить її заново. Файл `.env`, конфігурація каналів, медіаконтент, статистика й архіви не видаляються.

## 6. Налаштування `.env`

Приклад:

```env
BOT_TOKEN=1234567890:REPLACE_WITH_REAL_TOKEN
OWNER_ID=123456789
ADMIN_IDS=

AUTO_START=1
BOT_LANGUAGE=ua
TIMEZONE=Europe/Kyiv
SCHEDULER_POLL_SECONDS=20
NOTIFY_OWNER=1
```

| Параметр | Обов'язковий | Призначення |
| --- | --- | --- |
| `BOT_TOKEN` | так | токен нового бота від `@BotFather` |
| `OWNER_ID` | так | цифровий Telegram ID власника |
| `ADMIN_IDS` | ні | додаткові ID через кому |
| `AUTO_START` | ні | `1` — увімкнути автоматичний розклад |
| `BOT_LANGUAGE` | ні | мова службового інтерфейсу; поточний інтерфейс український |
| `TIMEZONE` | ні | часовий пояс для ранкових/денних/вечірніх підписів |
| `SCHEDULER_POLL_SECONDS` | ні | частота перевірки розкладу, мінімум 5 секунд |
| `NOTIFY_OWNER` | ні | `1` — повідомляти власника про нові помилки |

`BOT_TOKEN` не можна надсилати стороннім особам або публікувати в GitHub. Якщо токен став відомий сторонній людині, його потрібно перевипустити через `@BotFather`.

## 7. Підготовка Telegram-бота й каналів

1. Створіть бота через `@BotFather` командою `/newbot`.
2. Скопіюйте токен у `.env`.
3. Додайте бота адміністратором кожного цільового каналу.
4. Надайте право публікувати повідомлення.
5. Для публічного каналу використовуйте `@username`.
6. Для приватного каналу використовуйте цифровий ID формату `-100...`.

### Як правильно заповнювати `/addchannel`

Перший канал створюється безпосередньо в Telegram-боті командою:

```text
/addchannel key chat_id Назва для меню
```

Що це означає:

| Частина команди | Пояснення | Приклад |
| --- | --- | --- |
| `key` | коротка внутрішня назва профілю; вона ж назва папки з контентом | `HOTBOYS_YAOI_NS` |
| `chat_id` | Telegram-канал, куди бот має постити | `@HOT_BOYSES` або `-1001234567890` |
| `Назва для меню` | назва, яку буде видно в `/channels` і кнопках | `HOTBOYS + YAOI NS` |

Приклад для публічного каналу:

```text
/addchannel HOTBOYS_YAOI_NS @HOT_BOYSES HOTBOYS + YAOI NS
```

Приклад для приватного каналу:

```text
/addchannel HOTBOYS_YAOI_NS -1001234567890 HOTBOYS + YAOI NS
```

Після успішного додавання бот створить:

```text
channels/HOTBOYS_YAOI_NS/photos
channels/HOTBOYS_YAOI_NS/videos
channels/HOTBOYS_YAOI_NS/archive/photos
channels/HOTBOYS_YAOI_NS/archive/videos
```

Правила для `key`: тільки латиниця, цифри, `_` або `-`, без пробілів. `key` створюється саме в момент успішного виконання `/addchannel`. Якщо треба змінити Telegram-канал для вже створеного профілю, використовуйте `/setchat key chat_id`. Якщо треба змінити назву в меню, використовуйте `/title key Нова назва`.

Новий канал створюється на паузі, щоб покупець спочатку додав контент і перевірив ручну публікацію.

Після зміни `.env` або коду перезапустіть процес бота.

## 8. Додавання контенту

### Варіант A. Через Telegram

```text
/upload HOTBOYS_YAOI_NS
```

Після цього надсилайте боту фото, відео або підтримувані медіафайли як документи. Завершення:

```text
/upload_stop
```

### Варіант B. Через папки на сервері

Копіюйте файли до потрібної черги:

```text
channels\HOTBOYS_YAOI_NS\photos
channels\HOTBOYS_YAOI_NS\videos
```

Підтримувані формати фото:

```text
.jpg .jpeg .png .webp
```

Підтримувані формати відео:

```text
.mp4 .mov .avi .mkv .webm
```

Фактична можливість надсилання конкретного файлу також залежить від чинних лімітів Telegram Bot API.

### Варіант C. Перенесення зі старих ботів

`import_media.ps1` копіює файли й не видаляє оригінали.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\import_media.ps1" `
  -Source "D:\OldBot\channels\source_profile" `
  -TargetKey "HOTBOYS_YAOI_NS"
```

Команду запускають окремо для кожного профілю, у який потрібно скопіювати старий контент. Значення `TargetKey` має збігатися з ключем, створеним командою `/addchannel`.

## 9. Як працює автопостинг

1. Бот перевіряє активні профілі через заданий інтервал.
2. Профілі без `chat_id`, вимкнені профілі та профілі на паузі пропускаються.
3. Бот вибирає фото або відео з черги.
4. Якщо є обидва типи медіа, він намагається чергувати їх.
5. Для вибраного файлу створюється підпис відповідною мовою.
6. Файл надсилається в Telegram-канал.
7. Після успішної публікації файл переноситься до `archive`.
8. Результат записується в статистику та лог.

Якщо публікація не вдалася, файл залишається в черзі. Бот збереже текст помилки й, якщо ввімкнено `NOTIFY_OWNER=1`, повідомить власника про нову помилку.

## 12. Налаштування підписів

Власний набір можна додати як JSON-файл у `caption_packs/`, використовуючи структуру наявних файлів. Для кожної мови `ua`, `ru`, `en` мають бути масиви:

```text
morning, day, evening, night, photo, video, cta
```

Щоб новий набір з'явився в команді `/pack`, розробнику потрібно додати його назву до дозволеного списку в `handlers/admin.py`.

## 16. Типові проблеми

### `Compatible Python was not found`

Не встановлено сумісний Python 3.10–3.12 або Windows не бачить команди `py`, `python` чи `python3`. Перевірте:

```powershell
py -3.12 --version
```

### `BOT_TOKEN не налаштовано`

Знову запустіть `start.bat`: майстер налаштування попросить вставити реальний токен. За потреби токен також можна змінити вручну у `.env`.

### `OWNER_ID не налаштовано`

Укажіть цифровий Telegram ID власника в `.env`.

### Бот не відповідає користувачу

Доступ мають лише власник і адміністратори. Перевірте `OWNER_ID`, `ADMIN_IDS` або список, сформований командами `/addadmin`.

### `Не вказано chat_id`

Виконайте:

```text
/setchat HOTBOYS_YAOI_NS @HOT_BOYSES
```

або використайте цифровий ID `-100...`.

### `Forbidden` або `not enough rights`

Додайте бота адміністратором цільового каналу та надайте право публікувати повідомлення.

### `chat not found`

Бот запущений, але Telegram не бачить цільовий канал. Виконайте `/checkchat HOTBOYS_YAOI_NS`, перевірте `@username` або числовий ID `-100...`, додайте бота в канал адміністратором і дайте право публікувати.

### `Черга порожня`

Додайте підтримувані файли через `/upload` або в папки `photos` і `videos` потрібного профілю.

### Публікації дублюються

Імовірно, старий медіабот продовжує працювати. Поставте новий бот на паузу, зупиніть старі процеси або завдання, виконайте один ручний тест і лише потім відновіть розклад.

### Файл опубліковано, але не перенесено в архів

Перевірте права облікового запису Windows на папку проєкту, вільне місце на диску та `logs\bot.log`.

Для автоматичної перевірки запустіть `diagnose.bat`. Він перевіряє Python, залежності, `.env`, доступ до службових папок, токен Telegram і права бота в доданих каналах. Перевірка не публікує повідомлень.

### Після зміни `.env` нічого не змінилося

Зупиніть і запустіть процес заново. `.env` читається під час старту програми.

## 17. Відомі обмеження поточної версії

- Бот публікує один медіафайл за одну операцію, а не альбом.
- У проєкті немає вебадмінки; керування виконується через Telegram і конфігураційні файли.
- Інтерфейс команд зараз українською, хоча підписи підтримують `ua`, `ru`, `en`.
- Зберігання локальне у JSON-файлах, тому ця версія розрахована на один запущений екземпляр програми.
- Бот не завантажує контент з інших каналів автоматично.
- Бот не перевіряє авторські права на завантажені медіафайли; за законність контенту відповідає власник каналів.
- Доступність форматів і максимальний розмір файлу залежать від правил Telegram Bot API.

Ці пункти слід чесно повідомити покупцю до оплати.
